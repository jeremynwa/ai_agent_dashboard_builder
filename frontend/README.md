# App Factory — Frontend

AI-powered platform for SK consultants. Four main scenarios:
1. **Dashboard generation** — Upload CSV/Excel or connect DB + prompt → AI generates React dashboard with live preview
2. **App review & deploy** — Drop ZIP → AI reviews quality → push to GitLab + request Azure VM
3. **Review Research** — Analyze Google Maps reviews via Outscraper + Claude
4. **Automation Builder** — Describe a process → Claude generates step-by-step automation

## Quick Start

```bash
npm install
npm run dev
```

Requires `frontend/.env` with API URLs and Cognito config (auto-generated by `lambda-v2/deploy.ps1`).

## Stack

- React 18 + Vite 7
- WebContainer (StackBlitz) for live preview
- Recharts for charts
- Motion.dev for animations
- AWS Cognito for auth
- Custom design system (ds.css, no Tailwind)

## AI Pipeline

```
Prompt + Data → Plan (Haiku) → User validates → Generate (Sonnet) → Compile
→ Parallel Review (4× Haiku agents) → Vision Analysis → Dashboard Ready
```

Key features:
- **Dashboard Planning** — Haiku pre-generates a structured plan (pages, KPIs, charts) for user validation before generation
- **Parallel Multi-Agent Review** — 4 specialized Haiku agents (security, perf, quality, data/viz) run in parallel
- **User Memory** — Persistent preferences (industry, feedback history) stored in DynamoDB, injected into prompts
- **Context Reset** — Each pipeline phase receives only the minimum context needed
- **Recharts API Reference** — Anti-hallucination reference prevents obsolete/invalid API usage

- `src/services/export.js` — Zip export
- `src/components/` — AuthProvider, Login, MatrixRain, FileUpload, DbConnect, ClarificationChat, DashboardPlan, IntakeChat, UploadCode, ReviewResults, DeployForm, MyApps, ReviewResearch, AutomationChat, AutomationBuilder

## Backend

See `lambda-v2/` for the Lambda backend (SAM, 12 functions). The generate Lambda supports:

- **Standard mode**: Monolithic system prompt in `generate/index.mjs`
- **Agent Skills (beta)**: Modular skills uploaded to Anthropic (dashboard-generator, data-analyzer, industry skills, reviewer, vision)
- **Plan mode**: `modelHint: 'plan'` → Haiku returns structured dashboard plan
- **Parallel review**: `parallelReview()` → 4 Haiku agents diagnose issues in parallel

Deploy: `cd lambda-v2 && .\deploy.ps1`
